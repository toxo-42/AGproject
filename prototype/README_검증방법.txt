PeOb 주행 기록 무결성 검증 안내
================================

이 폴더(압축을 푼 폴더)에는 아래 4개 파일이 들어있습니다.

  pedal_XXXXXXXX_XXXXXX.csv       실제 주행 기록 (엑셀로 열어볼 수 있는 표 형식 파일)
  pedal_XXXXXXXX_XXXXXX.csv.sig   위 기록 파일에 대한 "전자 서명"
  pubkey.pem                       서명을 확인하는 데 쓰는 "공개키"
  verify_signature.py              서명이 맞는지 검사해주는 프로그램
  README_검증방법.txt              지금 보고 계신 이 안내문

------------------------------------------------------------------
왜 검증이 필요한가요?
------------------------------------------------------------------
pedal_XXXXXXXX_XXXXXX.csv 파일은 스마트폰에서 자동으로 기록된 원본 그대로의
내용이며, 아무나 열어볼 수 있는 일반 텍스트(CSV) 파일입니다.

다만 일반 파일이기 때문에 이론적으로는 메모장 등으로 열어 내용을 고칠 수도
있습니다. 그래서 "이 파일이 정말 스마트폰이 기록한 그대로이고, 그 이후 단 한
글자도 바뀌지 않았다"는 것을 증명하기 위해 .sig(서명) 파일을 같이 제공합니다.

verify_signature.py 프로그램으로 검사하면:
  - 파일이 원본 그대로라면        -> "VALID" (정상)
  - 파일이 조금이라도 바뀌었다면  -> "INVALID" (변조 의심)
라고 알려줍니다.

------------------------------------------------------------------
검증 방법 (Windows)
------------------------------------------------------------------
1. Python이 설치되어 있지 않다면 먼저 설치합니다.
   - 인터넷 브라우저에서 python.org 접속 → Downloads → Python 설치 파일 다운로드 후 실행.
   - 설치 화면 맨 아래 "Add python.exe to PATH" 체크박스를 반드시 체크하고 설치하세요.

2. 이 파일들이 들어있는 폴더를 엽니다.

3. 폴더 안 빈 곳에서 Shift 키를 누른 채 마우스 오른쪽 버튼을 클릭 →
   "여기에 PowerShell 창 열기" 또는 "여기서 명령 창 열기"를 선택합니다.

4. 열린 검은/파란 창에 아래처럼 입력하고 Enter를 누릅니다.
   (아래 XXXXXXXX_XXXXXX 부분은 실제 파일 이름으로 바꿔주세요)

       python verify_signature.py pedal_XXXXXXXX_XXXXXX.csv

5. 화면에 "VALID"가 나오면 정상, "INVALID"가 나오면 변조된 것입니다.

------------------------------------------------------------------
검증 방법 (Mac)
------------------------------------------------------------------
1. Mac에는 보통 Python이 이미 설치되어 있습니다(따로 설치 필요 없음).

2. 이 파일들이 들어있는 폴더를 Finder로 엽니다.

3. 터미널(Terminal) 앱을 엽니다(Spotlight 검색 Cmd+Space → "터미널" 입력).

4. 터미널 창에 "cd " (cd 뒤에 띄어쓰기 한 번)까지만 입력한 다음,
   이 파일들이 들어있는 폴더를 Finder에서 터미널 창으로 그대로 끌어다 놓으면
   폴더 경로가 자동으로 입력됩니다. 그 상태에서 Enter를 누릅니다.

5. 아래처럼 입력하고 Enter를 누릅니다.
   (아래 XXXXXXXX_XXXXXX 부분은 실제 파일 이름으로 바꿔주세요)

       python3 verify_signature.py pedal_XXXXXXXX_XXXXXX.csv

6. 화면에 "VALID"가 나오면 정상, "INVALID"가 나오면 변조된 것입니다.

------------------------------------------------------------------
참고
------------------------------------------------------------------
- 이 검증 프로그램은 인터넷 연결이나 별도 설치가 필요 없습니다(Python만 있으면 됩니다).
- CSV 파일 내용은 누구나 열어볼 수 있습니다(암호화되어 있지 않음). 이 서명은
  "내용을 숨기는 것"이 아니라 "원본인지 확인하는 것"이 목적입니다.
- 검증 결과가 "INVALID"로 나온다면, 압축을 다시 풀거나 다른 프로그램(엑셀 등)으로
  파일을 열었다가 저장한 적이 있는지 먼저 확인해보세요 — 그런 경우에도 내용이
  미세하게 바뀌어 INVALID로 나올 수 있습니다.
